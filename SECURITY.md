# Security Policy

inovaea devices run on networks and control equipment, so we take security seriously.

## Reporting a vulnerability

**Please do not report security issues in public issues.**

Use GitHub private vulnerability reporting:
[Report a vulnerability](https://github.com/ctrl32/inovaea/security/advisories/new)

Please include:

- affected component (firmware, hardware) and version
- steps to reproduce
- potential impact

We aim to acknowledge reports within 7 days and to release a fix as soon as
reasonably possible. Reporters will be credited unless they prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
